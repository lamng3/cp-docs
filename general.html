1_General

General

Starters and tools. These are not tied to one division.

Starters

USACO Guide module: Generic_Code.

  • contest.cpp. Default contest file.
  • leetcode.cpp. LeetCode method stub.
  • minimal.cpp. Shortest starter.
  • oi.cpp. OI starter.
  • template.py. Python starter.

Tools

USACO Guide module: Running_Code_Locally.

  • cpnew. Copy a template into a new file.
  • cpgen. Fetch a LeetCode problem and write the stub.
  • cptest. Run a solution against cached examples.

cpbuild compiles a file with warnings and sanitizers. It is a shell function in the repository README, not a file in tools/.
